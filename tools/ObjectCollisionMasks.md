# 오브젝트 충돌 마스크

`Assets/Resources/Sprites` 아래 원본 PNG 옆에 같은 크기의 `원본이름_collision.png`를 둡니다.

- 충돌색은 마스크 이미지의 **맨 왼쪽 위 1픽셀**로 지정합니다. 이 픽셀 자체는 충돌이 아닙니다.
- 원본 그림의 투명한 부분에 칠한 영역도 충돌에 포함합니다. 원본의 알파는 검사하지 않습니다.
- 각 조각은 Sprite Editor의 슬라이스 사각형 안에서 읽습니다. 사각형 밖까지 칠해야 한다면 해당 슬라이스에 여백을 포함하세요. 마스크 자체가 투명한 픽셀은 충돌이 아닙니다.
- 지정한 색과 RGB가 정확히 같은 픽셀만 사용합니다. 색칠할 때 안티앨리어싱 없이 단색을 쓰세요.
- 판정은 **슬라이스별**입니다. 유효한 색칠이 없는 조각은 기존 사각형 발판을 유지합니다. 모든 충돌을 없애는 의미가 아닙니다.
- 마스크가 있으면 해당 오브젝트의 사각형 충돌을 대체합니다. 별도로 칠한 `Blocked`/물/절벽/다른 오브젝트는 계속 막습니다.
- 앞뒤 그리기 기준점은 기존과 같습니다. 색칠 마스크에는 `idle` 그림의 발바닥 행을 대입합니다. 오른쪽은 발바닥의 맨 오른쪽 끝, 왼쪽과 위쪽은 맨 왼쪽 끝을 기준으로 잡고, 같은 행의 실제 발바닥 픽셀 전체도 함께 검사합니다. 그래서 한쪽 발끝만 마스크 밖으로 빠져 몸이 오브젝트 안에 들어갈 수 없습니다. 아래쪽은 두 발의 가운데를 기준으로 잡습니다. 달리기 중 발 들림에도 기준점은 일정합니다. 마스크 없는 사각형은 기존 판정을 유지합니다. NPC 경로와 배치 검사는 충돌 픽셀이 걸친 칸을 보수적으로 피합니다.
- 색칠 마스크에 닿거나 그 안을 지나는 플레이어는 바라보는 방향과 이동 방향에 관계없이 해당 오브젝트보다 항상 앞으로 그려집니다.

PNG 가져오기·수정·삭제, Play 진입, 빌드 전 자동 변환됩니다. 수동 실행은 `Tools > Farm MVP > Rebuild Object Collision Masks`입니다.
결과는 `Assets/Resources/ObjectCollisionMasks.asset`에 저장됩니다. 실행 중에는 이 카탈로그를 한 번 읽고 스프라이트별 비트 배열을 공유합니다. PNG 탐색/색상 읽기는 하지 않습니다.

적용 경로: `Fixed` 장식, `Objects` 마커, 잔해, 설치물, 나무, 바위. 바닥 장식이나 열린 문처럼 원래 충돌이 없는 상태는 그대로 통과합니다.
`Object_지역`/`Objects_지역`과 `Fixed_지역`/`Fixed_번호_지역`은 대소문자를 구분하지 않습니다. `Objects`에도 등록되지 않은 일반 PNG 타일을 놓을 수 있으며, 그림과 충돌은 `Fixed`처럼 적용됩니다.
다 자란 나무는 전체 모습(`TreeArt.Full`)의 마스크를 사용하고, 묘목/그루터기는 해당 모습의 마스크를 사용합니다.
계절 그림은 실제 사용한 스프라이트의 마스크를 사용합니다. 다른 계절 그림에 마스크가 없으면 그 계절에는 기존 사각형으로 돌아갑니다.
시각 효과의 흔들림이나 애니메이션 프레임마다 충돌을 바꾸지 않고 배치/상태 갱신 시점의 모양을 사용합니다.

현재 테스트 파일:

| 조각 | 판정 | 비트 데이터 |
|---|---|---|
| Wood_spring_0, Wood_spring_1 | 기존 사각형 | 없음 |
| Wood_spring_2 | 529개 충돌 픽셀 | 178바이트 |
| Wood_spring_3 | 1,922개 충돌 픽셀 | 530바이트 |

검증: `tools/Check-ObjectCollision.ps1`은 별도의 임시 Unity 프로젝트에서 원본 투명 영역의 색칠 보존/색상표/슬라이스 분리, 배치 위치, 제거·겹침, 문 개폐, 얇은 마스크 이동, 실제 발바닥 접촉 위치를 검사합니다.
`-Scene` 옵션은 저장된 `Main.unity`와 리소스 복사본으로 농장을 생성하고, 실제 Wood 오브젝트들의 마스크 누락과 다른 장애물에 의한 막힘을 보고합니다. 원본 씬과 세이브는 변경하지 않습니다.
