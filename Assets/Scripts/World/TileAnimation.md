# 타일 애니메이션 사용법

1. 이미지를 `Assets/Resources/Sprites/Tiles/Animation` 또는 그 하위 폴더에 넣습니다.
2. Unity에서 Sprite Mode를 Multiple로 설정하고 Sprite Editor에서 원하는 크기로 Slice → Apply합니다.
   16×16, 16×32, 32×32 등 크기에 제한이 없으며, 코드가 슬라이스/피벗/PPU를 바꾸지 않습니다.
3. 첫 번째 스프라이트를 Tile Palette에 넣어 **일반 Tile**을 만들고 게임의 표시용 타일맵에 칠합니다.
4. Play하면 GameLocation이 맵을 만들 때 자동으로 애니메이션 타일로 바꿉니다.
   별도 Animated Tile 에셋이나 Animator는 필요 없습니다. 마커/충돌 전용 레이어는 대상이 아닙니다.

이미지 한 장의 모든 슬라이스가 애니메이션 하나입니다. 이미지의 왼쪽에서 오른쪽으로,
여러 줄이면 위쪽 줄부터 아래쪽 줄로 순서대로 반복합니다. 슬라이스 이름을 바꿔도 순서는 같습니다.
첫 번째 대신 다른 프레임으로 칠해도 같은 애니메이션이 첫 프레임부터 재생됩니다.
한 조각뿐인 이미지는 정지 상태로 유지하고 Animation 폴더 밖의 이미지는 자동 애니메이션 대상에서 제외합니다.

`Beach_1.png`를 16×16으로 나누면 그 파일 안의 8프레임을 재생합니다.
`Beach_2.png`는 별개의 애니메이션입니다. `Beach.png`처럼 서로 다른 모양을 여러 줄에 모아 둔
통합 시트는 모든 줄이 연속으로 재생되므로, 이 팩에서는 모양별 개별 PNG를 사용하세요.

기본 속도는 초당 8프레임이며 `AnimationTileset.FramesPerSecond`에서 변경합니다.
Tilemap의 Animation Frame Rate가 1일 때 이 속도로 재생됩니다.
슬라이스를 수정했다면 Play를 종료한 뒤 다시 실행하세요.
에디터의 원본 타일/씬/임포트 설정은 자동 변환으로 저장되거나 수정되지 않습니다.

기존 시트 이름/번호 간격 등록표와 계절별 프레임 애니메이션은 제거했습니다.
계절별 정지 이미지 교체와 캐릭터/상호작용 애니메이션은 별도 기능으로 유지합니다.
