# 완전 투명 타일 정리

Unity 메뉴 **Tools → FarmMVP → 완전 투명 타일 지우기**에서 엽니다.

1. **대상 범위**를 고릅니다.
   - **모든 타일맵**: 현재 열린 모든 씬의 타일맵. 비활성 오브젝트도 포함합니다.
   - **지역 전체**: Farm, DeepForest 등 선택한 지역의 모든 레이어.
   - **지역 + 타일맵 종류**: 지역과 Location / Cliff / Water / Fixed 등 레이어를 함께 선택합니다. 계절 접두사, 번호가 붙은 중첩 레이어, 이전 이름 형식도 인식합니다.
   - **특정 타일맵**: Hierarchy의 Tilemap을 끌어 넣습니다.
   - **선택한 부모 아래**: Grid 등 부모 오브젝트 아래를 정리합니다. 사용자 지정 이름의 타일맵에도 사용할 수 있습니다.
2. 필요하면 **특정 타일 에셋만**에 Tile 에셋을 넣습니다. 비워 두면 모든 타일 종류를 검사합니다.
3. 일부 구역만 지우려면 **사각형 영역만 검사**를 켭니다. 시작 셀과 크기를 입력하거나 **Scene에서 영역 드래그 선택**을 누른 뒤 Scene 뷰에서 왼쪽 버튼으로 드래그합니다. Esc로 선택을 취소합니다.
   - 시작 셀은 포함하고, `시작 + 크기` 좌표는 제외합니다.
   - 여러 타일맵을 고르면 각각의 **로컬 셀 좌표**에 같은 범위를 적용합니다. 드래그 기준 타일맵은 창에 표시됩니다.
   - Z 시작과 깊이는 입력값을 따릅니다. 사각형 제한을 끄면 모든 Z층을 검사합니다.
4. **투명 타일 검사**로 타일맵별 삭제 대상 수를 확인합니다.
5. **범위 내 투명 타일 모두 지우기**를 누릅니다. 이 버튼은 최신 상태를 다시 검사한 후 삭제합니다. 검사 도중 취소하면 삭제하지 않습니다.
6. 결과를 확인하고 씬을 저장합니다. **Ctrl+Z** 한 번으로 여러 타일맵의 변경을 함께 되돌릴 수 있습니다.

## 판정 기준

- 잘린 스프라이트 영역의 모든 픽셀이 정확히 알파 0일 때만 삭제합니다. 단 한 픽셀이라도 알파가 남아 있으면 보존합니다.
- 색상 알파, 꺼진 Renderer, 비활성 오브젝트 때문에 안 보이는 타일은 이미지 자체가 투명하지 않으면 보존합니다.
- 애니메이션, 계절 타일, RuleTile은 모든 참조 스프라이트를 검사합니다. 어느 프레임·계절·규칙에서라도 그림이 있으면 보존합니다.
- `Resources/Sprites/Tiles/Animation` 아래의 일반 Tile은 실행 시 애니메이션으로 변환되므로 같은 이미지 파일의 모든 프레임을 검사합니다.
- 일반 Tile 중 계절 폴더/계절 이름으로 실행 시 자동 변환될 가능성이 있는 타일은 보수적으로 보존합니다. 명시적인 SeasonalTile은 모든 계절 그림으로 판정합니다.
- 스프라이트가 없는 타일은 기본적으로 보존합니다. **스프라이트 없는 타일도**를 켜면 포함합니다. Objects/Blocked 등의 의도적인 마커를 정리할 때는 대상 범위를 확인하세요.
- GameObject를 생성하는 타일, 지원하지 않는 사용자 정의 TileBase, 읽지 못한 이미지는 보존합니다. 판정 불가 개수와 읽기 오류는 창에 표시됩니다.
- 원본 Tile/텍스처/팔레트/프리팹 에셋을 삭제하지 않습니다. 씬의 배치된 셀만 지우며, 프리팹 인스턴스의 변경은 override로 기록합니다.
- Read/Write가 꺼진 텍스처도 설정 변경 없이 검사합니다. 플레이 모드에서는 삭제할 수 없습니다. 닫힌 씬과 Prefab Mode는 작업 대상에 포함하지 않습니다.

## 검증

`tools/Check-TransparentTileCleaner.ps1`은 Temp 아래에 별도의 Unity 프로젝트를 만들어 실제 Unity에서 검사합니다. 열린 작업 씬을 변경하지 않습니다. 그래픽 장치가 필요한 읽기 불가 텍스처 검사, 잘린 이미지, 미세 알파, 범위·종류 필터, 계절·애니메이션 보존, 삭제 및 Undo/Redo, 프리팹 인스턴스를 검증합니다.
