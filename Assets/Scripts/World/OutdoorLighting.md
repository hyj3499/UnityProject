# 야외 시간대 조명

게임 시작 시 `GameManager.Boot`에서 자동 생성한다. 씬에 컴포넌트를 붙일 필요는 없다.

| 게임 시각 | 야외 조명 |
| --- | --- |
| 06:00–09:00 | 밝고 옅은 주황/분홍 아침빛 → 원래 색 |
| 09:00–17:00 | 원래 색, 가장 선명한 낮 |
| 17:00–18:00 | 저녁 초입, 낮빛 유지 |
| 18:00–19:00 | 따뜻한 주황 노을이 점차 짙어짐 |
| 19:00–19:30 | 어두운 붉은 노을 |
| 19:30–20:00 | 밤빛으로 어두워짐 |
| 20:00–다음 날 02:00 | 어두운 밤 밝기 유지 |

새벽 2시에 기존 수면 처리로 다음 날 6시가 된다. 시간표 자체는 02:00–06:00에도 밤빛을 반환한다.
밤에는 야외를 크게 어둡게 하되 지형의 윤곽이 보일 정도의 푸른 잔광을 남긴다.

`OutdoorLightingCycle.cs`의 색 상수로 아침, 노을, 밤의 색과 밝기를 조절한다.
조명은 `GameManager.LightingMinutes`의 연속 시간을 사용한다. HUD는 기존처럼 10분 단위로 표시하며,
시간이 정지한 메뉴/대화에서는 조명도 멈춘다. 시간 이동, 저장 불러오기, 다음 날 시작에는 현재 시각의 조명을 즉시 적용한다.

현재 프로젝트의 기본 2D 렌더링에 맞춰 `Resources/OutdoorLighting.shader`로 월드 색을 곱한다.
원본 스프라이트와 타일의 색, ScreenSpaceOverlay HUD, `MapGraph.IsIndoor`인 실내는 보존된다.
구름 그림자와 조명은 같은 시간표를 사용한다. 조명은 구름 위, 낚시 느낌표 아래에 그려진다.

검증: `powershell -File tools/Check-OutdoorLighting.ps1`. 별도 임시 Unity 프로젝트에서 전체 스크립트를
컴파일하고 시간 경계, 연속 시각, 실제 렌더 픽셀, HUD 보존, 실내 전환, 카메라 이동/확대를 검사한다.
결과와 시간별 PNG는 `Temp/latest-lighting-check.txt`에 적힌 경로에 저장된다.
