# 마법 차징 / 타격 이펙트

- 좌클릭을 누르면 조준, 놓으면 한 번에 시전한다. 물·바람도 동일하다.
- 0 / 0.5 / 1 / 1.5 / 2 / 2.5초: 1×1 → 3×1 → 3×3 → 3×6 → 6×6 → 6×9.
- 크기는 **바라보는 방향의 가로 폭 × 전방 길이**다. 첫 줄은 캐릭터 바로 앞이며, 이동·방향 전환을 따라간다. 폭이 6이면 왼쪽 2칸, 중심 1칸, 오른쪽 3칸이다.
- 적용할 수 있는 칸은 마법 색, 적용할 수 없는 칸은 어두운 색이다. 맵 밖은 표시하거나 시전하지 않는다.
- 낚시는 기존처럼 한 칸이다. 대지도 범위 시전되지만 별도의 신규 이미지 지정은 없다.
- 최대 MP는 10,000이다. 기존 세이브도 다음 실행 때 10,000/10,000으로 올린다.
- MP는 실제 적용 대상 수 × 기존 마법 비용이다. MP가 부족하면 플레이어에서 가까운 대상부터 가능한 수만큼 시전한다. 시간은 한 번의 시전 비용만 소모한다.
- 큰 바위·통나무는 여러 칸이 범위에 포함되어도 한 번만 타격/과금/표시한다.
- 마법 변경, 맵 변경, UI/원형 메뉴, 창 포커스 상실 시 진행 중인 차징을 취소한다.

| 마법 | 시트 | 표시 위치 |
| --- | --- | --- |
| 물 | magic1.png | 물을 준 타일 |
| 바람 | magic2.png | 제거한 풀 또는 수확한 작물 타일 |
| 바위 | magic3.png | 바위 중심 (땅 복원/설치물 철거는 타일) |
| 삽 | magic4.png | 파낸 타일 |
| 칼날 | magic5.png | 나무 밑동/통나무 중심, 시전 방향으로 회전 |

`Resources/Sprites/MagicEffects`의 PNG를 64×64 프레임으로 왼쪽부터 나누어 초당 12프레임으로 한 번 재생한다. 원본 이미지는 수정하지 않는다. 이펙트 크기는 32 pixels/unit(캔버스 한 프레임 = 2타일)이며, 바닥 이펙트는 타일 아래끝에 맞춘다. 대상 발밑의 Y좌표를 기준으로 화면 아래쪽이 위쪽 이펙트를 가린다.

충전 속도는 `MagicCharge.SecondsPerStage`, 재생 속도는 `MagicEffect.FramesPerSecond`에서 조절한다. 차징 전용 캐릭터 애니메이션은 아직 추가하지 않았다.

검사: 프로젝트 루트에서 `./tools/Check-Magic.ps1`. Temp 아래 별도 프로젝트에서 실행하며 실제 씬·세이브를 사용하지 않는다.
