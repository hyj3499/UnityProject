# 마법 차징 / 타격 이펙트

- 좌클릭을 누르면 조준, 놓으면 한 번에 시전한다. 물·바람도 동일하다.
- 0 / 0.5 / 1 / 1.5 / 2 / 2.5초: 1×1 → 3×1 → 3×3 → 3×6 → 6×6 → 6×9.
- 크기는 **바라보는 방향의 가로 폭 × 전방 길이**다. 첫 줄은 캐릭터 바로 앞이며, 이동·방향 전환을 따라간다. 폭이 6이면 왼쪽 2칸, 중심 1칸, 오른쪽 3칸이다.
- 적용할 수 있는 칸은 마법 색, 적용할 수 없는 칸은 어두운 색이다. 맵 밖은 표시하거나 시전하지 않는다.
- 낚시는 기존처럼 한 칸이다. 대지는 범위 안의 경작 대상에 magic6을 표시한다.
- 최대 MP는 10,000이다. 기존 세이브도 다음 실행 때 10,000/10,000으로 올린다.
- MP는 실제 적용 대상 수 × 기존 마법 비용이다. MP가 부족하면 플레이어에서 가까운 대상부터 가능한 수만큼 시전한다. 시전으로 시간을 추가하지 않으며, 게임 시계는 평소처럼 실시간으로 흐른다.
- 큰 바위·통나무는 여러 칸이 범위에 포함되어도 한 번만 타격/과금/표시한다.
- 마법 변경, 맵 변경, UI/원형 메뉴, 창 포커스 상실 시 진행 중인 차징을 취소한다.

| 칼날: 큰 통나무 | magic10.png | Wood_spring의 네 번째 밑바닥 중앙 |

`Resources/Sprites/MagicEffects`의 PNG를 왼쪽부터 나누어 초당 12프레임으로 한 번 재생한다. 프레임 크기는 magic5: 48×48, magic7: 80×48, magic8: 128×128, magic10: 128×64이며 나머지는 64×64다. 시트별 프레임 수는 magic1부터 순서대로 13, 9, 7, 8, 14, 10, 12, 12, 13, 15장이다.

원본 이미지는 수정하지 않는다. 기본 이펙트는 **32 pixels/unit** 크기다. magic1/2/4/6의 아래 중앙(발생점)을 타일 중앙에 둔다. magic5는 48×48 프레임을 16×16의 3×3 격자로 나눈 **3열 3행(오른쪽 아래) 칸의 중심**이 나뭇가지 타일에 겹쳐 회전한다. 회전축은 Unity 픽셀 좌표로 (40,8)이다.

magic7/8/9/10은 기본 크기 변경의 영향을 받지 않고 원본 종횡비를 유지하면서 대상 오브젝트의 가로·세로를 덮도록 맞춘다. 투명 여백을 감안한 15% 여유를 두며, **magic7은 이 크기의 두 배**다. Trees는 모든 종류·성장 단계에서 magic9를 **64×64픽셀(4×4타일)**로 통일한다. magic9/10의 아래 중앙은 오브젝트 밑바닥 중앙에 고정하고 세운 방향을 유지한다. 크기·위치는 파괴 전에 확보한다.

대상 발밑의 Y좌표를 기준으로 화면 아래쪽이 위쪽 이펙트를 가린다. 계절이 바뀌어도 같은 종류에는 같은 이펙트를 사용한다.

충전 속도는 `MagicCharge.SecondsPerStage`, 재생 속도는 `MagicEffect.FramesPerSecond`에서 조절한다. 차징 전용 캐릭터 애니메이션은 아직 추가하지 않았다.

검사: 프로젝트 루트에서 `./tools/Check-Magic.ps1`. Temp 아래 별도 프로젝트에서 실행하며 실제 씬·세이브를 사용하지 않는다.
`-RenderPreview`를 붙이면 실제 바위·나무 아트로 비교 이미지 `effect-alignment.png`도 해당 Temp 프로젝트에 생성한다.
