# 눈과 머리 기준점

- `Base/base_animations_headguide.png`: 몸체와 같은 192×480 시트. 각 32×32 프레임에 빨간 픽셀 하나를 둔다. 현재 빨강은 `#AC3232`; 순수 빨강도 인식한다. 가이드는 화면에 그리지 않는다.
- `Base/eyes.png`: 128×64. 위 행은 눈 1, 아래 행은 눈 2. 각 행의 32×32 칸은 정면 뜸 / 정면 감음 / 측면 뜸 / 측면 감음 순서다.
- 눈 그림의 기준 목 좌표는 각 칸의 좌상단부터 `(16,18)` 픽셀 중심이다. 눈을 다시 그릴 때 이 기준을 유지한다.
- 캐릭터 만들기의 `눈` 항목으로 종류를 선택한다. 기존 저장 데이터에서 선택이 비어 있으면 눈 1을 사용한다.
- 뒤를 보면 눈을 숨기고, 왼쪽은 위치와 그림을 함께 반전한다. 약 3.5초마다 눈을 깜빡이며, 상호작용 3번째 프레임과 점프 3·4번째 프레임은 감은 눈을 사용한다. 측면 달리기도 일반 측면 눈을 사용한다.
- Idle은 방향별 첫 번째 프레임 하나만 사용하며 몸은 고정되고 눈만 깜빡인다.
- 몸체 PNG는 눈 없는 원본을 그대로 사용한다. 몸체의 눈 픽셀을 제거하거나 피부색으로 덮는 코드는 없다.
- 눈은 원본 색으로 표시한다. 적용되지 않는 눈 색 LUT/슬라이더는 캐릭터 UI에서 숨겼다. 미리보기 동작 버튼은 걷기 → 뛰기 → 멈추기 순서로 전환된다.

검증 코드: `tools/FarmerEyesChecks.cs` (격리 Unity 프로젝트의 Editor 폴더에 복사하여 `FarmerEyesChecks.Run` 실행).
