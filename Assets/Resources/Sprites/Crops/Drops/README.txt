바닥에 떨어졌을 때(월드 드랍) 쓸 그림을 여기에 넣는다.

  파일 이름 = 시트 이름에서 공백을 뺀 것.  예) Carrot.png, BellPepperRed.png, AdzukiBean.png

인벤토리 아이콘은 작물 시트의 마지막 번호(예: Sprites/Crops/Carrot_6)를 그대로 쓰고,
여기에 같은 이름의 그림이 있으면 <b>바닥에 떨어진 모습만</b> 그것으로 바뀐다.
없으면 인벤토리 아이콘을 그대로 쓰므로, 넣고 싶은 것만 하나씩 채워 넣으면 된다.

필요한 이름 (작물 하나당 하나):
  Adzuki Bean -> AdzukiBean        Aloe -> Aloe                  Asparagus -> Asparagus
  Beetroot -> Beetroot             Blackberry -> Blackberry      Blueberry -> Blueberry
  Broccoli -> Broccoli             Cabbage -> Cabbage            Carrot -> Carrot
  Cauliflower -> Cauliflower       Corn -> Corn                  Cucumber -> Cucumber
  Eggplant -> Eggplant             Grapes -> Grapes              Green Beans -> GreenBeans
  Hot Pepper -> HotPepper          Melon -> Melon                Onion -> Onion
  Parsnip -> Parsnip               Pineapple -> Pineapple        Potato -> Potato
  Pumpkin -> Pumpkin               Rice -> Rice                  Spring Onion -> SpringOnion
  Strawberry -> Strawberry         Sunflower -> Sunflower        Tomato -> Tomato
  Watermelon -> Watermelon

  파프리카는 색깔마다 따로: BellPepperOrange, BellPepperGreen, BellPepperRed
